# 🤖 AI Resume Screening & ATS Analyzer

An AI-powered Resume Screening & ATS Analyzer built using **Python**, **Streamlit**, **PyMuPDF**, and **Scikit-learn**. This application helps users evaluate how well their resume matches a job description by calculating an ATS (Applicant Tracking System) score and providing actionable feedback.

---

## ✨ Features

- 📄 Upload Resume (PDF)
- 📝 Extract Resume Text
- 🛠️ Detect Technical Skills
- 🎯 Calculate ATS Match Score
- ✅ Display Matching Skills
- ❌ Display Missing Skills
- 📊 Interactive Skill Match Visualization
- 💡 Resume Improvement Suggestions
- 🤖 AI Resume Feedback

---

## 🛠️ Tech Stack

- **Streamlit**

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Kriti21-hub/resume-screening-ai.git
```

### 2. Move into the project folder

```bash
cd resume-screening-ai
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```

---

## 📊 How It Works

1. Upload your resume in PDF format.
2. Paste a job description.
3. The application extracts resume text.
4. Technical skills are detected.
5. The ATS score is calculated.
6. Matching and missing skills are displayed.
7. AI-generated feedback suggests improvements.
